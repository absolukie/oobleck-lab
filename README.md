# Oobleck Lab

A 2D non-Newtonian fluid sandbox. Poke it, pour it, smack it.

**Physics:** position-based fluids (PBF-lite) with per-material rheology —
- **Oobleck** — shear-thickening: smack it and it jams solid, stir gently and it flows
- **Slime** — viscoelastic: stretches, snaps back, bounces
- **Ketchup** — shear-thinning with yield stress: sits still until shaken
- **Honey** — Newtonian, very viscous
- **Water** — Newtonian, thin (the control group)

**Tools:** stir 🖐️ · pour 🚰 · hammer 🔨 · drop the ball 🎱 · tilt gravity 📱 · clear 🗑️

Single `index.html`, no build step, no dependencies. Deploys on Cloudflare Pages via Connect-to-Git.
